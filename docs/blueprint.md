# **App Name**: PrimalImageTutorial

## Core Features:

- Step Display: Display tutorial steps clearly.
- Download Links: Provide links to downloads (pydroid3, Firefox, cookie editor).
- External Links: Link to bing image creator and github repository
- Platform Support: Ensure compatibility across mobile and PC.

## Style Guidelines:

- Primary color: Dark gray (#333) for the background.
- Secondary color: Light gray (#f0f0f0) for content areas.
- Accent: Blue (#007BFF) for links and important elements.
- Clear and readable font for tutorial steps.
- Mobile-first design with responsive layout.
